# AquaSafe School Submission Checklist

Use this checklist before submitting the project.

- [ ] Add your name, school/institution, subject/module, teacher/lecturer and submission date to `README.md`.
- [ ] Create the GitHub repository, for example `AquaSafe-Durban`.
- [ ] Upload/push every file in this folder to the repository.
- [ ] Confirm the default branch is `main`.
- [ ] Open `AquaSafe_Final_3_Model_ML_Lifecycle.ipynb` on GitHub and confirm it renders.
- [ ] Confirm `app.py` is present in the repository root.
- [ ] Confirm `requirements.txt` is present in the repository root.
- [ ] Deploy `app.py` on Streamlit Community Cloud.
- [ ] Test every Streamlit tab after deployment.
- [ ] Test the Community Risk Map with internet access.
- [ ] Add the final GitHub URL to `README.md`.
- [ ] Add the final Streamlit URL to `README.md`.
- [ ] Submit the notebook, GitHub link and Streamlit link according to your school instructions.

## Suggested submission items

1. `AquaSafe_Final_3_Model_ML_Lifecycle.ipynb`
2. GitHub repository URL
3. Streamlit Community Cloud URL
4. README/documentation
5. Any report or presentation required by your school
